تتبع العملات الرقمية المسروقة: أداة مجانية لضحايا النصب

أداة مجانية ومفتوحة المصدر تساعد ضحايا الاحتيال على تتبّع مسار الأموال المسروقة وإعداد ملف منظّم يمكن تقديمه للبنوك والمنصات والجهات الرسمية. الواجهة بالعربية أولًا وتدعم 7 لغات.

تحميل من GitHub

ماذا تفعل؟
  • تتبع العناوين على Bitcoin وEthereum وTRON وLitecoin وSolana
  • كشف المنصات المعروفة من قاعدة تسميات موثّقة فقط
  • تقرير يمكن تقديمه للمحامي أو الشرطة
  • يعمل على جهازك ولا يرسل بياناتك لأي جهة
تنبيه
الأداة تساعد على التتبع ولا تضمن استرداد الأموال. احذر ممن يعدونك باسترداد الأموال مقابل دفعة مقدمة.

Crypto Fraud Tracer

A free, open-source tool that helps crypto fraud victims trace stolen funds and prepare a clear case file for banks, exchanges and authorities. Arabic-first UI, 7 languages.

  • Bitcoin, Ethereum, TRON, Litecoin, Solana tracing
  • Exchange identification from documented labels only
  • Runs locally; your data stays on your machine

Get it on GitHub

It helps with tracing and does not guarantee recovery of funds. Beware of anyone promising recovery for an upfront fee.
